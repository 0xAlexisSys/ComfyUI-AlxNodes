# ComfyUI-AlxNodes

Helper nodes for [ComfyUI](https://github.com/comfyanonymous/ComfyUI).

## Install

```bash
cd custom_nodes
git clone https://gitlab.com/AlxArch010/ComfyUI-AlxNodes # or drop in the folder manually
```

Then start ComfyUI.

## Nodes

### Drop Alpha

|        |                 |
| ------ | --------------- |
| Input  | `image` - Image |
| Output | `IMAGE` - Image |

Strips the alpha channel (if available) from an input image and outputs the RGB image. When passing a RGBA image generated by a model (e.g., Qwen-Image-2.1) to a node like RTX Video Super Resolution, this can be useful.

### Empty Latent Image QoL

|        |                       |
| ------ | --------------------- |
| Input  | `preset` - Combo      |
| Input  | `width` - Integer     |
| Input  | `height` - Integer    |
| Input  | `flip` - Integer      |
| Input  | `batch_size` - Height |
| Output | `LATENT` - Latent     |

Same as the Empty Latent Image node, but with quality-of-life additions. `width`, `height`, and `flip` are exposed if `preset` is set to `custom`.
